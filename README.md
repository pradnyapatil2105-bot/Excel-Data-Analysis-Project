# Zomato Restaurant Analysis Dashboard

An interactive Excel dashboard analyzing Zomato restaurant data to understand ratings, cuisines, average cost, and online delivery availability.

## Objective
To explore restaurant data, identify trends, and understand customer preferences using Excel.

## Dataset
Zomato restaurant data covering ratings, cuisines, average cost, and online delivery availability.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers
- Conditional Formatting
- Excel formulas

## What I Did
1. Analyzed Zomato restaurant data to explore ratings, cuisines, average cost, and online delivery availability
2. Used PivotTables and PivotCharts to summarize restaurant performance and identify trends
3. Applied Excel formulas, slicers, and conditional formatting to support interactive data exploration
4. Presented key findings through charts and visual summaries to understand restaurant data and customer preferences
